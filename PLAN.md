# cars-zeekr — план MVP на 2 недели

Сайт автосалона по ТЗ ([docs/tz-autosalon.pdf](docs/tz-autosalon.pdf)).
Дизайн-референс: [Figma «Electro-auto»](https://www.figma.com/design/ILS9KLBbDioKcrUhp90SwK/Electro-auto?node-id=0-1).

## Рамки MVP

Полный ТЗ — это объём на 2–3 месяца командой. За 2 недели соло делаем **рабочий вертикальный срез**:
каталог → карточка → бронирование → лиды → мини-админка, на одном бренде **Zeekr**.

Решения по скоупу (отклонения от ТЗ зафиксированы явно):

| Тема | Решение для MVP | Полный ТЗ |
|------|-----------------|-----------|
| Бренд / ассортимент | Только **Zeekr** (001, 7, X, 009). На макетах Toyota — заменяем. | Мульти-бренд |
| Платежи | **Mock-провайдер** (эмуляция вебхука «оплачено»). Провайдер выберем позже. | СБП / Т-Банк / Сбер |
| Предоплата | **Процент от цены** по умолчанию + ручная сумма в заявке при одобрении админом. | фикс или % |
| Файлы | **MinIO** (S3-совместимый) локально. | S3 в облаке |
| Авто с пробегом | **Базово в MVP**: каталог + фильтр по пробегу + карточка used (модель `Car` с `condition`). | Полные разделы |
| Регистрация | **Обязательна для заявок**: пользователь входит/регистрируется, заявки видит в личном кабинете. | — |
| SEO/SSR | Базовые meta + ЧПУ + sitemap/robots. SSR — после MVP. | Полный SSR/SSG |
| Баннеры, калькулятор | Калькулятор рассрочки отправляет заявку после подтверждения. Баннер скидки создаёт защищённую заявку. | Полный CRUD/ротация |
| Регистрация пользователей | **Добавлено сверх ТЗ**: JWT, личный кабинет, смена пароля, блок `@gmail` → модалка 451. | — |

## Стек

FastAPI + PostgreSQL + Redis + Alembic · React + TypeScript + Vite · Docker Compose · MinIO.
Админка — **SQLAdmin** (CRUD в стиле Django admin поверх SQLAlchemy, минимальный дизайн).
Уведомления о заявках — **Telegram-бот**. Карты — **Яндекс.Карты**.
Публичные заявки и предоплата идут через профиль пользователя: CTA → вход/регистрация
→ заявка → одобрение в SQLAdmin → предоплата в личном кабинете.

## Ключевое требование заказчика

При регистрации **запрещены адреса на `@gmail.com`**. Бэкенд отвечает `451 Unavailable For Legal Reasons`,
фронт показывает модалку: «По законодательству РФ мы не можем зарегистрировать пользователя с gmail почтой».

## Подтверждённые решения

- Предоплата — **процент от цены** по умолчанию; админ может указать сумму
  предоплаты в конкретной заявке.
- Регистрация — **обязательна для заявок**: покупка, бронь, скидка и рассрочка
  требуют аккаунт и создают заявку в личном кабинете.
- Личный кабинет содержит редактируемые имя/телефон, смену пароля и историю
  заявок. После одобрения заявки админом пользователь получает переход к
  предоплате.
- Авто с пробегом — **в MVP, базово** (каталог + фильтр по пробегу + карточка).
- Реальный платёжный провайдер — **решим позже**, пока mock с расширяемой архитектурой.
