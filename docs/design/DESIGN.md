## Цвета (Figma variables)

| Токен | Hex | Применение |
|-------|-----|------------|
| `--color-black` | `#262626` | header/footer фон, основной текст, заголовки |
| `--color-white` | `#FFFFFF` | фон страниц, текст на тёмном |
| `--color-gray` | `#737373` | вторичный текст, подписи |
| `--color-red` | `#CA0100` | **акцент**: CTA-кнопки, ценники, бейджи выгоды, активные состояния |

## Типографика

Шрифт — **Roboto** (подтверждено заказчиком). Навигация — **CAPS**, заголовки секций — крупные bold
по центру (напр. H1 ~40px Bold), цены — bold.

## Раскладка

- Контейнер десктоп **1440px**, мобайл **320px** (брейкпоинты 320 / 768 / 1200+).
- **Header** ~165px: тёмный (`black`), красный лого слева, верхняя строка (телефон/адрес/соцсети) + меню CAPS (Каталог авто, Авто с пробегом, Кредит и рассрочка, Спецпредложения).
- **Footer** ~333px: тёмный, колонки навигации + реквизиты + контакты + соцсети.
- Секции чередуют белый фон и `gray-400`; карточки на белом с тонким бордером `gray-300`.

## Ключевые компоненты

- **Карточка авто** (повторяемая): фото, название+комплектация, ТТХ-иконки, **красный ценник**, кнопки «Купить» (red) / «Подробнее» (outline).
- **Бейдж выгоды**: красный pill «Выгода до N ₽».
- **Быстрый подбор**: слайдер цены, селекты (кузов, КПП…), счётчик «Найдено N», красная кнопка «Показать».
- **Промо-баннер** «Перебьём предложения конкурентов»: тёмный/красный блок с полем телефона.
- **Модалки**: «Купить/Оставить заявку» (форма), «Спасибо за обращение!» (подтверждение).
- **Карточка авто (детальная)**: промо с выбором цвета кузова (цветные точки), 4 преимущества с красными иконками, галерея (большое фото + сетка миниатюр), таблица комплектаций + «Купить», 3 колонки характеристик (Безопасность / Экстерьер / Интерьер), карусель «Похожие предложения».
- **Карусели**: промо-слайдер главной, галерея фото, «похожие», логотипы банков-партнёров.

## Детали компонентов (по скриншотам заказчика 16.06.2026)

### Header (2 строки)
- **Верхняя (тёмная):** лого «Electro-avto» (→ Zeekr) + красный бейдж «5 лет — превосходим ваши ожидания»; ссылки «Подбор авто» (active, red), «О компании», «Контакты»; справа геолокация (адрес).
- **Нижняя:** меню CAPS «КАТАЛОГ АВТО / АВТО С ПРОБЕГОМ / КРЕДИТ И РАССРОЧКА / СПЕЦПРЕДЛОЖЕНИЯ» (активный — red); соц-иконки (TikTok, Telegram, Instagram, WhatsApp, телефон).
- Хлебные крошки под хедером: «Главная / Раздел».

### Footer (тёмный)
Колонки навигации (Каталог авто, Авто с пробегом, Кредит и рассрочка, Спецпредложения, Контакты) · блок «Реквизиты» (юрлицо/адрес) · телефоны + режим работы (Ежедневно 08:00–21:00) · лого. *Реквизиты/телефоны на макете — placeholder.*

### Блок «Я ищу» / «Быстрый подбор» (это и есть «поиск»)
Поля: **Марка, Модель, Тип привода, Коробка передач, Тип двигателя, Цена от, Цена до**; слева — сетка логотипов брендов (мультибренд; для MVP — Zeekr). Красная кнопка-счётчик **«НАЙДЕНО N авто»** (динамический). На каталоге/б-у/спецпредложениях вариант с слайдером цены (0–3 млн) + Тип кузова + Коробка + «ПОКАЗАТЬ».

### Карточка авто (лицо в сетке)
Фото + бейдж «Выгода N ₽» (red), название+комплектация, статус «В наличии с ПТС», «В наличии: N авто», «Доступна в N цветах», 4 иконки ТТХ (**л.с., расход л/100км, разгон 0–100 с, макс. скорость км/ч**), **цена** + старая цена (зачёркнута), кнопки «Купить» / «Подробнее» (на детальной — «Забронировать»).

### Карточка авто (детальная)
- Промо: выбор цвета кузова (точки), бейдж выгоды, цена/старая цена.
- 4 преимущества с красными иконками; подарки (Страхование / Оборудование / Комплект резины — «в подарок»).
- Галерея: большое фото + миниатюры.
- **Таблица комплектаций** (Trim): колонки `Комплектация | Двигатель (объём + л.с.) | Коробка передач | Привод | Цена | Со скидкой`.
- 3 колонки характеристик с красными буллетами: **Безопасность / Экстерьер / Интерьер**.
- Карусель «Похожие предложения» (красная стрелка).

### Кредит/рассрочка (для будущего этапа)
Баннер «Условия» (3 пункта) → Шаг 1 «Ваш будущий автомобиль» (Марка/Модель/Комплектация + цена + платёж/мес) → Шаг 2 слайдеры (срок мес., первонач. взнос) → Шаг 3 ПДн (имя, телефон, подарок, «Оставить заявку») → Банки-партнёры (Сбер, ВТБ, Альфа).

> Валюта на макетах смешана («с»/сом и «₽») — placeholder, выносим в конфиг (открытый вопрос ТЗ).
