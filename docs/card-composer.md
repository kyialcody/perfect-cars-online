# Карточка авто (админка)

Как из админки завести, отредактировать, скрыть и удалить автомобиль. **Карточка —
это само авто**: всё содержимое (герой, цвета, комплектации, преимущества, подарки,
характеристики, фото) заполняется на **одной форме**. Нет черновиков, отдельного
«сборщика» и кнопок «Собрать/Опубликовать» — созданное авто сразу на сайте.

> Раздел касается прежде всего **новых** автомобилей; форма поддерживает и авто с
> пробегом (поля «Состояние», «Год», «Пробег»).

## Коротко: жизненный цикл

```
Создать авто (Каталог → Авто → Создать)  →  сразу на сайте
        │
        ▼
Редактировать ту же форму в любой момент
        │
        ▼
Скрыть с сайта / Показать  ⇄  is_hidden  (скрытое убрано отовсюду, деталка 404)
```

Видимость — это один флаг **`is_hidden`**:

| Состояние | Где видно |
|---|---|
| на сайте (`is_hidden = false`, по умолчанию) | каталог, списки, `/car/{slug}`, похожие, подборки главной |
| скрыто (`is_hidden = true`) | нигде (деталка отдаёт 404, бронь/заявка по нему запрещены) |

## Перед началом: что должно быть в справочниках

Форма предлагает **только выбор** из уже созданного. Поэтому заранее заполни нужное
в разделе **Справочники** (вписать новое значение прямо в форме авто нельзя):

- **Бренд** и **Модель** (модель обязательна для авто)
- **Тип кузова**, **Тип двигателя**
- **КПП**, **Привод** (для комплектаций)
- **Цвет** (название + HEX)

> Если нужного значения нет — добавь его в соответствующем справочнике, и оно сразу
> появится в выпадающих списках формы авто.

## Список «Авто»

Раздел **Каталог → Авто** — простая таблица: ID, авто (бренд + модель, slug),
состояние, видимость (**На сайте / Скрыто**), цена, количество. В каждой строке:

- **Редактировать** — открыть форму авто.
- **Скрыть / Показать** — переключить видимость на сайте.
- **Удалить** — удалить авто целиком (вместе с комплектациями, фото и т.д.).

Кнопка **«+ Создать авто»** сверху открывает пустую форму.

## Форма авто (создание = редактирование)

Одна страница сверху вниз повторяет публичную карточку.

### Основное (герой)
- **Slug** — адрес карточки `/car/{slug}`, уникальный.
- **Состояние** — `Новое` / `С пробегом`.
- **Модель** (обязательна) / **Тип кузова** / **Тип двигателя** — выбор из справочников.
- **Цена**, **Старая цена** — старая зачёркивается на сайте.
- **Бейдж выгоды** (напр. «Выгода до 600 000 ₽»), **Статус-текст** («В наличии с ПТС»).
- Спеки героя: **Мощность**, **Расход / запас хода**, **Разгон 0–100**, **Макс. скорость**
  — пустые поля просто не показываются.
- **Год** и **Пробег** — для авто с пробегом.
- **Количество**, **В наличии**, **Промо**.

### Фото для каталога
**Фото в каталоге** — превью-карточка в каталоге и в похожих предложениях
(независимо от баннеров цветов и галереи). **Размер 1000×750 px (4:3).** «Убрать»
очищает фото.

### Цвета и баннеры
Отметь минимум **один** цвет из справочника. К каждому отмеченному цвету загрузи
**свой баннер** (**1440×480 px, 3:1**) — большой баннер вверху карточки авто это
картинка выбранного цвета (1 цвет = 1 картинка). На странице переключение цвета
меняет баннер. Минимум один цвет обязателен — иначе карточку не сохранить.

> Баннеры имеют фиксированный размер. Если загрузить картинку в правильных
> пропорциях — она не обрежется; иначе лишнее обрежется по краям.

### Комплектации
Таблица как на сайте: название, объём, мощность, **КПП**, **Привод**, цена и цена со
скидкой, порядок.
- Существующие строки правятся на месте.
- Чтобы **добавить** — заполни одну из пустых строк внизу (минимум название).
- Чтобы **удалить** — отметь галочку «удалить».
- **Фото комплектации** — у каждой строки своя загрузка фото (**640×360 px, 16:9**);
  оно показывается в блоке этой комплектации на странице авто. «Убрать фото» очищает его.

### Преимущества (чипы героя)
Иконка (`percent` / `trade` / `gift` / `shield`), текст, порядок, чекбокс «активно».
Неактивные на сайт не выводятся.

### Подарки
Текст подарка + порядок.

### Характеристики
Три блока — **Безопасность / Экстерьер / Интерьер**. Каждая строка — один пункт.

### Фото
- Существующие: **порядок**, **главное** (radio), **удалить**.
- **Добавить фото** — выбери один или несколько файлов; они встанут после текущих.
  Главным останется выбранное; если не выбрано — им станет первое фото.

Нажми **«Создать авто»** (новое) / **«Сохранить»** (существующее). Изменения сразу
появляются на сайте (кэш каталога обновляется автоматически). Ссылка **«Открыть на
сайте»** ведёт на готовую карточку.

## Скрыть / показать

Кнопка видимости есть и в списке, и на форме авто:
- **«Скрыть с сайта»** → авто исчезает из каталога, списков, похожих и подборок
  главной, а `/car/{slug}` отдаёт **404**. Бронь и заявка по скрытому авто запрещены.
- **«Показать на сайте»** → возвращает обратно.

## Частые вопросы

- **Создал авто — оно сразу на сайте?** Да. Скрывать нужно явно кнопкой.
- **Slug занят.** Форма не даст сохранить — выбери другой slug.
- **Пустой блок на карточке.** Пустые спеки/блоки не рендерятся — это нормально.
- **Удалить карточку целиком.** Кнопка «Удалить» в списке «Авто» (вместе с авто
  удаляются его комплектации, фото и т.д.).
